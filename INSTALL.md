# 🛠 Гайд по установке FunPay Bot

Все максимально просто, справится даже твоя бабушка. 

### 1. Подготовка
Тебе нужен установленный **Python 3.9** или выше. Если нет — качай с оф. сайта.

### 2. Скачивание
Клонируй репозиторий или просто скачай архив с кодом и распакуй в удобную папку.

### 3. Установка зависимостей
Открой терминал (или PowerShell) в папке с ботом и пропиши:
```bash
pip install -r requirements.txt
```

### 4. Настройка (Самое важное)
Открой файл `config.py` через любой текстовый редактор (хоть через блокнот) и заполни данные:

1. **GOLDEN_KEY** — Твой ключ авторизации FunPay. 
   - Заходишь на FunPay через браузер.
   - Жмешь `F12` -> `Application` -> `Cookies`.
   - Ищешь значение `golden_key` и копируешь его.
2. **TELEGRAM_BOT_TOKEN** — Пишешь [@BotFather](https://t.me/BotFather) в телеге, создаешь бота и забираешь токен.
3. **TELEGRAM_ADMIN_ID** — Твой ID в телеге. Можно узнать у [@getmyid_bot](https://t.me/getmyid_bot).
4. **GEMINI_API_KEY** — Если хочешь, чтобы отвечал ИИ. Если не надо — оставь пустым.

### 5. Запуск
Просто запускай файл `main.py`:
```bash
python main.py
```
Или нажми дважды на `start.bat`, если ты на Windows.

---
**Важно:** Файл `config.py` игнорируется гитом, так что твои данные не улетят в сеть при обновлении.
